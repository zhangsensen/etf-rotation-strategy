# 旧 ETF 因子挖掘的真实来源与证据边界

本页描述当前迁入的 v8 研究管线实际怎样得到因子组合、方向和权重。
它是来源审计，不是对旧因子有效性的重新认证。

```mermaid
flowchart LR
    A[人工编写因子公式] --> B[49只池内逐日横截面标准化]
    B --> C[23个启用因子组合枚举<br/>2至7因子]
    C --> D[180日IS / 60日OOS<br/>步进60日]
    D --> E[方向与权重<br/>IS IC符号和ICIR]
    E --> F[WFO筛选与FDR]
    F --> G[VEC / Train / Rolling / Holdout]
    G --> H[155个候选BT验证]
    H --> I[主策略与4因子备用]
```

## 什么是“挖掘”出来的

公式本身主要是人工预先编写：量价公式在
[`precise_factor_library_v2.py`](src/etf_strategy/core/precise_factor_library_v2.py)，
份额和融资公式在[`non_ohlcv_factors.py`](src/etf_strategy/core/non_ohlcv_factors.py)。
旧流程挖掘的是：从启用公式中选哪些因子、方向、相对权重、组合规模和候选排序。
它不是模型从原始K线自动创造数学公式。

真正启用清单在[`combo_wfo_config.yaml`](configs/combo_wfo_config.yaml)的`active_factors`：
17个OHLCV因子和6个份额/融资因子，共23个。注册表中的全部条目不是本次搜索空间。
组合规模为2至7；跨桶约束要求至少覆盖3个信息桶、每桶最多2个因子（2因子组合按可行桶数处理）。

## 每个窗口怎样计算

[`run_combo_wfo.py`](src/etf_strategy/run_combo_wfo.py)加载49只池、计算因子并按日期横截面处理：
有界因子做横截面rank并减0.5；无界因子做横截面Z-score和2.5%/97.5%截断。
因此分数是池内相对量，换成20只池必须重新计算。

[`combo_wfo_optimizer.py`](src/etf_strategy/core/combo_wfo_optimizer.py)使用180个交易日IS、
60日OOS、60日步进。在每个IS窗口内计算单因子IC：

- 窗口内绝对IC归一化，形成该窗口组合权重；
- IC为负的因子翻转，绝对IC低于0.01时默认不翻转；
- 在OOS比较候选调仓频率的IC，并计算含成本的近似组合收益、夏普与回撤；
- 全部窗口结束后，用窗口IC符号一致性确定保存方向，用IC均值/标准差得到保存ICIR；
- 最终BT按`abs(ICIR)`重新归一化权重。

旧封版记录的漏斗为266463→100000→200→200→156→155→155。
本轮没有重新跑26万组合；该数字是旧封版产物的来源记录。
最终候选排序又使用Train Calmar、Rolling最差收益、Holdout Calmar的百分位，权重30%/40%/30%。
Holdout参与过滤和排名，所以已被用于选择。

## 新发现的标签问题

当前WFO入口构造的是：

```python
returns_df = close.pct_change()
```

而单因子IC实现逐日比较`signals[t]`与`returns[t]`。多数价格因子需要`t`日收盘才能得到，
`returns[t]`却是`t-1收盘→t收盘`，信号在这段收益结束后才可知。
因此这组IC不能解释为预测能力，也不应继续承担方向、权重或因子认证。

组合OOS IC的另一段实现使用`signal[start-1]`评估后续收益，时序更接近研究合同；
但所谓`T1_OPEN`的WFO收益仍由收盘收益数组近似，不是实际开盘成交回报。
最终BT使用后续开盘成交，能证明冻结组合在模拟执行中的历史表现；它不能消除候选发现和元数据生成阶段的标签污染。

### 时序判定

Verdict: **FAIL**
Layer: **Factor / Certification**

- Signal time：因子最晚在D日收盘后可知。
- 旧单因子IC标签：D-1收盘→D收盘。
- 最早正常可执行价格：D+1开盘；旧正式BT实际链路为D数据→D+1决策→D+2开盘。
- Leak risk：高（用于因子方向与权重来源）；最终BT成交时序本身另行通过核对。

Required fix：新研究将发现标签明确为`open(D+1)→open(D+1+H)`，或至少让因子日期严格早于收益起点；
研究IC和可执行收益分栏，不能仅通过移动数组名称修复。旧结果保留作基线，不覆盖。

## 下一轮最短路径

1. 固定49只池、23个公式和当前执行，不扩展因子库。
2. 先为每个实际因子建立公式、单位、可获得时点、缺失规则和手算样例；优先融资、份额、绝对价格斜率。
3. 用可执行开盘到开盘标签重算单因子方向、稳定性及逐项增量证据。
4. 在看组合收益以前冻结少量候选，再做滚动评估；旧Holdout只作已见数据，不再承担确认职责。

只有因子方向和边际贡献经正确标签验证后，才进入20只池迁移。20只池尚缺旧策略需要的完整份额/融资数据合同。

### 份额因子的可用时点修正

上述v3表按`fund_share.trade_date`直接放置信号，接口又没有可用于证明盘前已知的公告时间，
所以其中份额因子的结果只能解释为公式日期诊断。v4将四个份额因子统一滞后一个交易日，
再以新的可用日匹配下一开盘收益；融资明细暂保留零额外滞后，因为官方口径是上一交易日数据
约在次日8:30更新，但进入正式管线前仍需记录实际抓取时间。

保守滞后后，`SHARE_CHG_5D/10D/20D`的5日IC分别约为-0.0375、-0.0460、-0.0383，
`SHARE_ACCEL`约为+0.0304，四者仍通过原研究筛选。这个结果支持把份额变化保留为下一轮候选，
不构成因子认证，也不恢复旧权重。证据和命令在本地
`runtime_outputs/etf_factor_recertification_20260918_v4_pit_lag1/`。
